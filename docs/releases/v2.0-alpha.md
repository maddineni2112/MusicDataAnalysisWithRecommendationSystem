# v2.0-alpha Release Notes

Release date: 2026-07-24

## Summary

`v2.0-alpha` is the first portfolio-ready platform milestone for **Indian Music Intelligence Platform**. It preserves the original v1.0 academic notebook/report/PPT and demonstrates a working local full-stack music intelligence platform through the existing portfolio.

## What Is Included

- v1.0 archive under `archive/v1.0/`.
- PostgreSQL-backed FastAPI service with public read APIs and protected admin APIs.
- Django music shell linked from the existing portfolio local project card.
- Docker Compose local demo with API, Django shell, and PostgreSQL.
- Sample CSV and public playlist-style JSON imports.
- Source lineage, raw snapshots, normalized tracks/artists/playlists, inferred labels, label overrides, job logs, model runs, recommendation runs, and recommendation results.
- Automatic Indian music labeling with confidence/evidence.
- TF-IDF recommender feature build and ignored local vector artifact fallback.
- Explainable hybrid recommendations with metadata, labels, official popularity, release era, diversity, and text similarity.
- Rule-based natural language recommender filters.
- Playlist holdout evaluation metrics stored in model runs.
- Dashboard, song explorer, artist explorer, artist network, recommender, model insights, data quality summary, and admin ops pages.
- Seed manifest workflow for future Indian music data acquisition across 8 language groups and 40 Spotify discovery queries.
- Render/Docker deployment configuration.
- Technical report source and exported PDF.
- Pitch deck source and exported PPTX.
- Local demo screenshots, including portfolio project card.

## Validation Evidence

Latest validation before tagging:

- `docker compose exec api ruff check app tests`
- `docker compose exec api python -m pytest -q`
- `docker compose exec api python -m app.cli models train --seed-limit 14 --result-limit 5`
- `docker compose exec api python -m app.cli seeds validate`
- `docker compose exec django python manage.py check`
- PDF/PPTX export structure check

## Known Alpha Limitations

- Full 100k-300k track dataset is not collected yet.
- Spotify live collection requires reviewed playlist IDs and API credentials.
- Production deployment is configured but not yet verified on a public host.
- Portfolio still points to the local music demo URL, not a deployed URL.
- Sentence-transformer embeddings and pgvector are not implemented yet.
- Popularity prediction remains deferred until official popularity coverage is large enough.
- Final `v2.0-beta` and `v2.0` release tags are still pending.

## Next Release Targets

`v2.0-beta` should focus on:

- production deployment,
- deployed portfolio link,
- larger reviewed dataset or documented deployable subset,
- stronger data quality/evaluation evidence,
- optional pgvector or embedding implementation if feasible.

`v2.0` should be tagged only after the deployed app, docs, portfolio integration, and release checklist are fully verified.
