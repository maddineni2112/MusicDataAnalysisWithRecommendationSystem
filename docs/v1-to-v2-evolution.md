# v1 to v2 Evolution

v1.0 was an academic notebook project using PySpark, regression, PCA similarity, and K-Means clustering on Spotify-style data.

v2.0 expands the work into a full-stack platform:

- PostgreSQL normalized data model
- FastAPI public/admin APIs
- Django portfolio shell
- React dashboard islands
- data import and quality jobs
- automatic Indian music labeling
- hybrid recommender
- model insight documentation
- deployment-ready structure
