# v1.0 Archive

This folder preserves the original academic version of the project before the v2 platform rebuild.

Included assets:

- `notebooks/MusicDataAnalysisNRecommendationSystem_code.ipynb`
- `MusicDataAnalysisNRecommendationSystem_report.pdf`
- `Music_Data_Analysis_Song_Recommendation.pptx`
- `recommender.py`

v1.0 focused on PySpark analysis, popularity prediction, PCA-based similarity, and K-Means clustering. v2.0 extends that work into a PostgreSQL-backed full-stack Indian music intelligence and recommendation platform.
